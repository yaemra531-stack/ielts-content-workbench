# 雅思 AI 图文工作台

我把内容流程整理好了，却发现每次开始做之前，还是要重新读一遍。

选题怎么想，正文怎么写，图片怎么拍。单独拿出来，我都有一些方法。但真要开始做一篇，又得把它们在脑子里重新排一遍。

还没动笔，就已经有点消耗了。

所以，我和 Codex 一起做了这个工作台，把已经讨论过的方法放进一个可以填写、可以随时停下来的网页里。

我想要的很具体。明天打开它，能知道上次做到哪里，眼前这一小步要做什么，然后接着做。

这就是「雅思 AI 图文工作台」。

它陪我把一个真实的雅思学习卡点，慢慢整理成一篇图文。从选题、验证方法，到写正文、准备拍摄，再到修改和导出，都能在这里留下记录。

我准备做的内容，是亲自用 AI 解决雅思学习中的问题。试了什么，哪里有用，哪里没用，把过程摆出来。文字可以口语一点，照片可以保留生活里的样子，重要的是有真实的事情可讲。

不过，真实的事情，也不一定在遇到的那一刻就能写成文章。

这也是我们后来加上「随手记一句」的原因。

打开它，只要回答一个问题，刚才具体卡在哪里？

写下来，点「保存为草稿」，今天就可以先到这里。它会留在笔记列表里。等哪天想继续做，再把这句话带进选题，补上自己的尝试和判断。

不用为了留住一个想法，当场把整篇文章都想清楚。

正式开始写的时候，左边能看到整套流程，右边只展开当前这一块。每块旁边都有一句常见卡点和最低完成标准，拿不准怎么下手时，可以先照着写一点。

目前一共 16 个板块，分成定位与选题、结构与视觉、成文与打磨三个阶段。

但用的时候，你可以跳着走。

有了标题，就先留标题。正文里某一段想清楚了，就先写那一段。拍摄还没准备好，也可以先把每张图要说明什么记下来。进度会分别保留，不需要排队等前一步全部结束。

以前容易漏掉的那些小事，也顺手放了进去。

写到一半要走，可以给自己留一句「下次从这里继续」。第二天回来，除了上次的板块，还能看到自己留下的具体提醒。做完一篇再新建，旧篇依然在，账号定位这些已经想过的内容也可以沿用。

做这个工作台的过程中，我们还试了三个 Skill。

你可以把它理解成给 Codex 的一套做事方法。碰到具体的问题，就请它按这个方法帮忙。页面里能看到的变化，有些来自这种配合。

先试的是费曼视角。

原来的选题表里，有刚需度、差异化、证据完整度。这些维度都是我们之前讨论过、留下来的。但看到「刚需度」三个字，和知道这一格该写什么，中间还隔着一点距离。

于是，我们把它展开成了一个问题，谁会在什么情况下被它卡住？

差异化也展开成了，你能补充什么亲自尝试的过程或发现？证据完整度，则问现在有什么证据，还缺什么？

现在打开第 04 步就能看到这些问题，原来的术语仍然留在括号里。原方法保留着，填写时多了一点具体的引导。这里只借用了费曼视角里「知道名字不等于理解」的思路，还没有变成一套检查整篇文章的自动功能。

第二个是拍摄参考。

写出一段方法之后，接下来还要想，纸怎么摆，镜头从哪里拍，手放在哪里。这个 Skill 就用在这里，把文稿里的意思变成可以对照的画面。

最初我们在第 13 步接了生图任务，要求每张准备 A/B 两种构图。后来实际看着页面，我反而不太清楚这一步究竟要做什么了。还没想明白画面，就有一堆要完成的格子。

聊下来，我发现自己现在更需要先看到合适的参考。它为什么适合这篇，我能借鉴哪个角度、怎样摆放，用手边的东西能不能做出来。

所以第 13 步改成了「找参考图」。接着上一页的配图重点，点「帮我找这张的参考」，把整理好的任务交给 Codex，先看看真实候选。选中后再放进工作台，留一句自己准备借鉴什么。图片或来源链接可以任选，也可以都留。

一张参考能指导几张配图，就沿用它。已经有思路的，也可以直接标记，不用再凑参考。以前放进去的 A/B 图片仍然保留，但不再要求每张都放两张，也不用在这里完成拍摄。

拍摄参考 Skill 还可以在需要时单独用。现在先试试，找到一张适合自己的参考，是否更容易动手。

第三个是产品评审，试完以后，我们反而决定先不改。

它提醒我们，第 13 步准备拍摄，却需要第 14 步的正文，编号可能让人误会先后顺序。这个提醒有道理，但聊清楚以后，我觉得原来讨论好的流程可以继续用。

所以，这次建议留作记录，没有改动流程。

我挺想保留这种选择。请 Skill 帮忙，是为了多看一眼自己没注意到的地方。它提出了建议，我们仍然要结合自己的用法决定。以后实际遇到哪一步麻烦，再请产品评审针对那一步检查，不必为了用上它，每次都找个地方改。

日常和 Codex 配合，还是点「请AI帮我处理这一步」，把整理好的任务复制过去，讨论、修改，再把结果填回来。这中间仍然有复制和回填。等实际用过几篇，知道哪个动作反复让人停下来，再具体改。

有一件事，我特别希望自己用久了也能记得。

验证结果可以是没用，也可以是暂时不知道。

一篇内容还没讲通，可以先留着。试过的办法没有达到预期，也值得记录。这个工作台里应该容得下这些过程，否则为了把格子填完，很容易反过来迁就表格。

要试用的话，用 Chrome 打开文件夹里的 `index.html` 就可以。已经配置过桌面入口的电脑，双击「雅思图文工作台」也能打开。先从「随手记一句」开始，存下一件你确实想解决的小事。

普通板块里的文字会自动保存。关掉前看一眼保存时间，上传图片时等它保存完。下次在同一台电脑、同一个 Chrome 用户配置里，从原来的入口打开，就能接着填。

完整备份还是要自己留一份。左侧的「备份全部笔记」会生成一个文件，里面带着笔记、进度和已经放入的参考图。想固定放在一个地方，可以在「备份保存位置」里选好文件夹并授权，以后优先直接存进去；没选目录时，仍然通过浏览器下载。换浏览器或者换电脑时，可以用它恢复。恢复会添加副本，目前还不会自动同步、合并两边的修改。

如果只是想把这篇文稿拿出来，第 16 步可以导出 Markdown。没写完，也能导出草稿。

更细的操作和维护方法，放在[使用说明](USAGE.md)里，需要时再翻就好。

说实话，这个系统还很新。

我们已经把主要功能搭起来，也做过保存、恢复和流程检查。但它到底能帮我少花多少精力，哪些设计用起来多余，还得靠接下来一篇一篇地做，才能知道。

我已经有点迫不及待，想拿它做第一轮完整练习了。

以后如果拿给朋友或者学员看，我也希望能带着自己做过的内容来讲。哪里顺手，哪里卡过，哪个方法后来被改掉，都有具体的东西可看。

眼下，先打开它，留下一句，做完一点。

下一次回来，能接着做。
